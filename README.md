# Explore With Me

Монолитный `main-service` был разделён на несколько независимых микросервисов. Для настройки и взаимодействия сервисов используется Spring Cloud.

## Архитектура и выделенные сервисы

Приложение разделено на следующие сервисы:

- **`user-service`** — управление пользователями.
- **`event-service`** — управление событиями, категориями и подборками.
- **`request-service`** — работа с заявками на участие в событиях.
- **`review-service`** — работа с комментариями к событиям.
- **`stats-server`** — сбор и хранение статистики просмотров.

Инфраструктурные сервисы:

- **`discovery-server`** — Eureka Server, в котором регистрируются сервисы.
- **`config-server`** — хранит конфигурации сервисов.
- **`gateway-server`** — единая точка входа в приложение. Внешние запросы проходят через Gateway и перенаправляются в нужный сервис.

Конфигурации сервисов находятся здесь:

```text
infra/config-server/src/main/resources/config
```

Каждый бизнес-сервис работает со своими данными и не обращается напрямую к базе другого сервиса.

## Межсервисное взаимодействие

Для взаимодействия между сервисами используется **OpenFeign**.

Основные связи:

```text
event-service
└── user-service

request-service
├── user-service
└── event-service

review-service
├── user-service
└── event-service

event-service
└── stats-server
```

Если сервису нужны данные из другого сервиса, он получает их через HTTP-запрос, а не через чужой репозиторий или таблицу базы данных.

Для получения нескольких пользователей или событий используются batch-запросы, чтобы не делать большое количество отдельных HTTP-вызовов.

## Внутренний API

### user-service

Получение пользователя:

```http
GET /internal/users/{userId}
```

Получение нескольких пользователей:

```http
GET /internal/users?ids=1,2,3
```

### event-service

Получение события:

```http
GET /internal/events/{eventId}
```

Получение нескольких событий:

```http
GET /internal/events?ids=1,2,3
```

Изменение количества подтверждённых заявок события:

```http
PATCH /internal/events/{eventId}/confirmed-requests?delta={delta}
```

Например:

```text
delta=1
```

увеличивает количество подтверждённых заявок, а

```text
delta=-1
```

уменьшает.

### stats-server

`event-service` обращается к сервису статистики для сохранения просмотров и получения статистики:

```http
POST /hit
GET /stats
```
